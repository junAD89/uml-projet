pour le projet front

# premiere etape

vous faites `npm install` au niveau de la racine du projet dans la console

# etape 2

apres ca
vous verrer l'apparition du dossier `node_modules`
si ca vient alors ca veut dire que c'est bon pour l installation

# etape 3

apres il faut que vous creer un ficher a la racine nomme `.env` a l interrieur vous metter `VITE_BACKEND_URL=http://127.0.0.1:5000`

# etape 4

lancer le front avec `npm run dev`
vous allez voir une url que vous allez mettre dans le navigateur et voila le front appareit
